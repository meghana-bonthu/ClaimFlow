# ClaimFlow Web

Angular 18 (standalone components, signals, new control flow) front end for the ClaimFlow API.

```bash
npm install
npm start          # http://localhost:4200, proxies /api to http://localhost:5080
npm run test:ci    # headless unit tests
npm run build      # production build in dist/
```

See the [main README](../../README.md) for the full project.
